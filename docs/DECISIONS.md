# Fractas 決まったこと・判断待ち（DECISIONS）

## 判断待ち（オーナー）

### D1. ポータルに出すのは、どちらの版か

- **いま**: ラジアル版（`portal-radial`）がポータル。正方形版（`main`）は GitHub Pages だけ。
- **選択肢**
  - **A.** ラジアル版のまま（何もしない）
  - **B.** 正方形版に入れ替える（同じ `fractas` の枠で）
  - **C.** 正方形版を別のゲームとして足す（新しい game_id と新しいページ）

| | A | B | C |
|---|---|---|---|
| 作業の量 | なし | 中（RUNBOOK の R6） | 大（ページ・一覧・説明文・キービジュアル・`game_catalog` への登録） |
| ランキング | 今のまま | ラジアル版の点と混ざる（桁が違う） | 分かれる |
| 危なさ | なし | 作りかけの部分が表に出る（色を見ない判定など） | 作業が多い |

- **おすすめ: A（当面）。** 正方形版は作り替えた直後の試作で、説明文・キービジュアル・ランキングの準備が無い。出すなら、今の遊び手とランキングを壊さない C のほうがよい。

### D2. ラジアル版の未公開の改良を出すか

- **中身**: `ce073ce`（古い Mac 向けの軽量化）と `d282cb6`（ハイスコアの保存・ミュートボタン・GAME OVER 画面の強化）。
- **選択肢**: A. 出す（RUNBOOK の R3）／ B. 出さない
- **影響**: 見た目と遊び心地が少し変わる。端末にハイスコアなどを保存するようになる（ゲームだけのキーなので問題なし）。
- **おすすめ: A。** ただし出す前に、ポータルの枠（縦長・スマホ）でボタンと GAME OVER 画面が崩れないかを確かめる。

### D3. このリポジトリを公開（PUBLIC）のままにするか

- **いきさつ**: 2026-07-26 に private で作ったが、別の環境で PUBLIC になった（GitHub Pages のため）。ほかのゲームのリポジトリは、ほとんど private。
- **選択肢**: A. PUBLIC のまま／ B. private に戻す
- **影響**: B にすると、無料プランでは GitHub Pages が止まる（正方形版の公開も止まる）。
- **おすすめ: D5 と一緒に決める。** Pages を続けるなら A。秘密の値が入っていないことは、2026-09-15 に確かめた（公開用の anon キーも入っていない）。

### D4. ランキングに昔の版の点が混ざっている件

- **いきさつ**: `plays` の fractas は 65 件（2026-09-15）。1位の 631,360 点（2026-06-05）はエンドレス版の点。`metadata.mode` で版を見分けられる（無し＝最初期、`60sec`、`turn3`）。
- **選択肢**
  - **A.** そのまま
  - **B.** 表示を `turn3` だけに絞る（ポータルの `js/scores.js` の変更＝Web スレッドの作業）
  - **C.** 古い記録を消す（本番の DB を変える＝オーナーのターミナルで）
- **おすすめ: B。** 記録は消さずに、表示だけ今の版にそろえる。

### D5. GitHub Pages で正方形版を公開し続けるか

- **選択肢**: A. 続ける／ B. やめる（GitHub の Settings → Pages）／ C. Pages をラジアル版（`portal-radial`）に向ける
- **影響**: A でも害は小さい（別の場所で遊べるだけ。そこでの点はポータルのランキングに入らない）。
- **おすすめ: D1 と一緒に決める。**
