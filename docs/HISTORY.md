## くわしく

### 2026-06-05 製品化とポータル掲載

- 元の試作は、12セクター×リングの極座標の盤面に、自動で走るスキャナーがあり、放っておいても消えていくエンドレスのゲームだった。
- 手を入れたところ: 名前を Fractas に統一、ページのタイトルと説明、はじめに出る操作のヒント（自動で消える）、「FRACTAS」の透かし、ポータルへのスコア送信（`SCORE_UPDATE`・10秒に1回・同じ点は送らない・離脱時に必ず送る）。ゲームの中身には触れていない。
- ポータル側: ページ（`games/fractas/index.html`・枠＋TOP5＋全ランキング）、トップのカード、`js/user-ui.js` の一覧、`js/i18n.js` の説明（英・日）、ランキングのタブ。
- サムネと動画: 本物の canvas から撮った（RUNBOOK の R9-2）。

### 2026-06-06 60秒版と SDK

- 別のAIが60秒のカウントダウンと GAME OVER を足した。時間切れ・結果の送信・再開を、実際のブラウザで確かめた。
- 「SDK にも対応を」という依頼に対して: ポータルの正式なやり方は iframe から `postMessage`（`docs/game-integration.html`）。そこで、ポータルの中ではそのまま、外で開いたときだけ公式SDKを読むようにした。
- 公式SDKが外のサイトから読めなかったので、ポータルの `_headers` に `/sdk/*` の CORS を足した。
- 気づいたこと: 自動スキャナーのせいで、放置でも60秒で約1,270万点入る。ランキングが腕前を表さない（→ 翌日のターン制で解消）。

### 2026-06-07〜08 ターン制と演出（別のAI・Codex）

- 時間制をやめ、「3手ごとに判定・マッチ0で GAME OVER」に。判定に成功するたびに色が増える（3→最大6）。
- 描画を軽い「光」の表現に作り直し、予約と判定のときだけ光るようにした。スキャナーをゆっくりに（0.35→0.04）。
- 音: Web Audio の環境音と効果音、回すときの小さな「チキチキ」、読み上げ（英語・女性の声を優先・音量 0.28）。
- 補充: 1つずつ光りながら入る。落下 1560ms・チャージ 1470ms・間隔 85ms。消える演出 920ms。

### 2026-07-26〜27 専用リポジトリと、別の環境での作り替え

- 他のゲームと同じく、専用のリポジトリを作った（private・6ファイル・43MB の Chrome の一時データなどは `.gitignore`）。
- 別の環境（旧 MacBook Pro ＋ Aider）が、軽量化 → ハイスコアなど → 正方形版へ作り替え、の順に push。リポジトリは PUBLIC＋GitHub Pages になった。

### 2026-08-20 公開のルールの変更と PR #3

- ルール: 自分のブランチ → `git merge origin/main` → PR → main にマージ＝公開。`npx wrangler deploy` は禁止。
- PR #3 は「hook と settings」だけ Web スレッドが取り込み済み。ゲームのファイルは PR の版のほうが演出が古かったので、閉じた（PR のブランチはその後に削除された。中身はコミット `9e6091d` として PR #3 から見られる）。
